MaxCompute CLI（maxc）0.5.0 已发布。这个版本的核心主题是把 CLI 从「人用的命令行」进一步打磨成「Agent 可调用的结构化工具层」。

{/* truncate */}

## 实时 agent manifest

新增 `maxc agent manifest --json`，由实时 parser 生成全部命令的参数、网络要求、凭据要求、副作用和输出形状。Agent 不再需要内置一份可能过期的命令清单——启动时拉一次 manifest，即为当前版本的权威契约。

## OAuth 可恢复登录

OAuth 登录、刷新和一次性 continuation 全面采用结构化 Envelope。`agent context` 保持纯本地检查，`agent doctor --online` 才执行在线验证，「已配置」不再被误读为「已认证」。

## 更严格的安全边界

- 工作区配置不再允许定义 `auth`，凭证只能来自用户级配置或显式 `--config`
- `data upload` 不再隐式创建分区，必须显式 `--create-partition`
- SQL 执行采用 SELECT-only 正向允许列表，未知操作 fail closed

完整的变更记录见 [CLI 版本说明](/docs/products/cli/release-notes/)，后续规划见 [CLI 路线图](/docs/products/cli/roadmap/)。

## 快速体验

```bash
aliyun maxc auth login --oauth --json
aliyun maxc agent doctor --online --json
aliyun maxc query "SELECT 1" --json
```
