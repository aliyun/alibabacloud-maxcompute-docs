## 产品目录

- [MaxCompute CLI](./cli/index.mdx)：进入命令行产品的安装与配置、命令参考和故障排查文档。
- [MaxCompute MCP Server](./mcp-server/index.mdx)：进入服务端产品的部署与配置、工具参考和安全权限文档。
- [MaxCompute Desktop](./desktop/index.mdx)：进入桌面产品的安装更新、使用指南和故障排查文档。

## 按任务选择

- 偏好命令行工作流时，选择 MaxCompute CLI。
- 需要连接智能应用时，选择 MaxCompute MCP Server。
- 偏好图形化桌面体验时，选择 MaxCompute Desktop。
