## 读写架构

![Source 从 MaxCompute 读取数据到 Flink SQL；Sink 从 Flink SQL 写入 MaxCompute；Catalog 提供表与分区元数据。](/img/flink-connector/read-write.png)

Source 是数据读取端，Sink 是数据写入端。Catalog 将 MaxCompute 表和分区的元数据映射到 Flink，帮助 SQL 作业发现和使用表。

## 开始前确认

本空间以 Connector 候选版本 **1.20.0** 的代码为依据，测试基线为 **Flink 1.20.4、JDK 17、Maven 3.9、MaxCompute Java SDK 0.61.2-public**。Connector 版本号与 Flink 版本号各自独立。

完整 OSS 历史产物与 latest 别名见[Connector JAR 下载](./downloads.mdx)。本空间的 1.20.0 候选目前从源码构建安装；本文不代表该版本已在 Maven Central 发布。存量读写具备本地测试记录；云端增量、CDC（变更数据捕获）、DLMV（增量物化视图）仍需目标服务验收。具体边界见[兼容性与交付语义](./compatibility.mdx)。
