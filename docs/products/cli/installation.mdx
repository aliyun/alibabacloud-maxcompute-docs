本页介绍 MaxCompute CLI 的安装与配置流程，帮助你在开始使用前确认运行环境可用。

## 选择安装方式

选择分发渠道时，请同时确认适用环境和版本差异。

## 安装

安装步骤将按操作系统或运行环境组织，并提供版本、权限要求和验证方法。

## 配置

配置项按名称、是否必选、默认值、作用域和示例值说明。请勿在配置或示例中使用真实凭证。

## 验证安装

安装完成后，请使用本节提供的验证方式确认 CLI 可以正常启动。

## 升级与卸载

升级或卸载前，请先确认兼容性、配置保留方式和清理范围。
