本页介绍 MaxCompute CLI（`maxc`）的全部安装渠道、环境要求和认证配置。

## 选择安装方式

| 渠道 | 命令入口 | 适用场景 | 环境要求 |
|------|---------|---------|---------|
| 阿里云 CLI 扩展（推荐） | `aliyun maxc` | 已使用或可使用阿里云 CLI | Alibaba Cloud CLI >= 3.3.3 |
| PyPI 独立入口 | `maxc` | 无法使用阿里云 CLI 扩展，或明确需要 PyPI 版本 | Python 3.9+ |
| 预编译二进制 | `maxc` | 无 Python 环境、Agent 沙箱、CI 镜像 | 主流 Linux / macOS / Windows |

三种渠道提供同一份命令集与 Envelope v2.0 输出契约，行为一致。

## 通过阿里云 CLI 安装

maxc 通过阿里云 CLI 分发，安装或更新阿里云 CLI 后即可使用：

```bash
# 安装最新版本（Linux / macOS）
/bin/bash -c "$(curl -fsSL https://aliyuncli.alicdn.com/install.sh)"

# macOS 也可以使用 Homebrew
brew install aliyun-cli
```

验证：

```bash
aliyun version          # 确认 >= 3.3.3，否则运行 aliyun upgrade
aliyun maxc --version
```

支持 Linux（AMD64/ARM64）、macOS（Intel 和 Apple Silicon）、Windows（AMD64）。

## 通过 PyPI 安装

```bash
python3 -m pip install --upgrade maxc-cli
maxc --version
```

## 预编译二进制

maxc 的 PyInstaller 预编译产物托管在 OSS，按版本和平台组织：

```text
https://maxcompute-repo.oss-cn-hangzhou.aliyuncs.com/maxc-cli/<version>/<platform>/maxc.tar.gz
```

- 最新版本号：`https://maxcompute-repo.oss-cn-hangzhou.aliyuncs.com/maxc-cli/versions/latest`
- 平台标识：`linux-amd64`、`linux-arm64`、`darwin-amd64`、`darwin-arm64`、`windows-amd64`
- 每个 tarball 附带同名 `.sha256` 校验文件，下载后请先校验再解包

[DSH 插件](./ecosystem.mdx)等集成方会在本地找不到 maxc 时自动从该地址下载托管副本。

## 认证方式

maxc 支持多种认证方式，按优先级推荐：

| 方式 | 命令 | 适用场景 |
|------|------|---------|
| OAuth（推荐） | `maxc auth login --oauth` | 交互式登录，浏览器授权，自动刷新 |
| 环境变量 | `maxc auth login --from-env` | 从 `ODPS_ACCESS_ID` / `ODPS_ACCESS_KEY` 读取 |
| AK/SK | `maxc auth login --access-id <id> --access-key-secret <secret>` | 显式凭证，写入 `~/.maxc/config.yaml`（权限 0600） |
| STS / 外部凭证进程 | `maxc auth login-external` | 由可信外部进程输出临时凭证 |

使用阿里云 CLI 入口时，`aliyun maxc` 直接复用 `aliyun configure` 配置的凭证体系。

注意事项：

- OAuth 回调始终监听 CLI 所在主机的 `127.0.0.1`；SSH 场景需配置端口转发，或在 CLI 同机浏览器完成授权
- 省略 `--project` 时弹出交互式项目选择器（需 TTY，仅支持中国区项目）；CI 用 `--no-picker`，非中国区用 `--catalog-endpoint` 覆盖
- 自动发现的工作区配置不允许定义 `auth`；凭证只能来自用户级 `~/.maxc/config.yaml` 或显式 `--config`

## 验证安装

```bash
# 本地就绪检查（不访问网络）
maxc agent context --json

# 在线就绪检查（验证身份与后端可达性）
maxc agent doctor --online --json
```

## 升级与卸载

- 阿里云 CLI 入口：`aliyun upgrade` 后 maxc 随之更新
- PyPI 入口：`python3 -m pip install --upgrade maxc-cli`
- 预编译二进制：重新下载新版本 tarball 覆盖即可
- 卸载：删除对应安装产物；本地配置和状态位于 `~/.maxc/`，按需保留或删除
