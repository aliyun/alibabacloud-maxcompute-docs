本页是 MaxCompute CLI 命令与参数的参考入口，可按命令名称查找语法、参数和示例。

## 命令分组

命令按用户任务分组，便于从目标快速定位所需命令。

## 命令条目结构

每个命令条目提供以下信息：

1. 用途和适用场景。
2. 完整语法。
3. 参数表及默认值。
4. 输入、输出和退出状态。
5. 经验证的示例。
6. 版本与兼容性说明。

## 全局选项

全局选项会同时说明优先级、作用域和与配置文件的覆盖关系。
