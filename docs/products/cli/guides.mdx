本页按用户目标组织 MaxCompute CLI 的操作指南，每篇聚焦一个可验证的结果。

## 发现数据

```bash
maxc meta search "销售" --json
maxc meta describe my_table --json
maxc meta partitions my_table --json
maxc data sample my_table --rows 5 --json
```

## 预估并执行查询

```bash
# 先预估成本
maxc query cost "SELECT * FROM large_table WHERE ds='20260601'" --json

# 执行，并限制成本上限
maxc query "SELECT * FROM large_table WHERE ds='20260601'" --cost-check 100 --json

# 结果写入 CSV
maxc query "SELECT * FROM large_table WHERE ds='20260601'" --output result.csv --output-format csv --json
```

## 异步查询

```bash
# 1. 提交并立即返回 job_id
JOB_ID=$(maxc query "SELECT * FROM large_table" --wait 0 --json | jq -r '.metadata.job_id')

# 2. 等待
maxc job wait "$JOB_ID" --timeout 600 --json

# 3. 获取结果（可分页）
maxc job result "$JOB_ID" --max-rows 1000 --json
```

## 数据导入导出

```bash
# 上传 CSV
maxc data upload my_table --file data.csv --partition "ds=20260601" --json

# 下载 CSV（默认拒绝覆盖已有文件）
maxc data download my_table --output data.csv --partition "ds=20260601" --json
```

## 权限检查

```bash
maxc auth can-i --table my_table --operation SELECT --json
```
