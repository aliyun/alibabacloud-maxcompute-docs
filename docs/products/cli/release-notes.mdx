本页按时间倒序记录 MaxCompute CLI 的版本变化。

## [0.7.0] — 2026-09-20

### Features

- 新增 `kb ask` / `kb search`：在本地知识库上做检索与问答，输出沿用统一 envelope。
- 新增 `mcp serve`：以 MCP server 形态对外提供命令能力，便于 agent 直接接入。

### Fixes

- 修复企业环境下 OAuth 登录与数据面请求报
  `SSL: CERTIFICATE_VERIFY_FAILED … unable to get local issuer certificate` 的问题。
  CLI 现在把系统信任根（macOS 钥匙串、系统 CA 文件）与内置 certifi 合并成一份临时
  bundle 后再发起请求，不再因为代理注入的根证书而丢掉公共根。
  仍可通过 `SSL_CERT_FILE` / `REQUESTS_CA_BUNDLE` 显式指定信任库，用户指定的文件优先，
  且不会被复制进合并结果。
- 上述合并同时覆盖数据面（PyODPS 的 REST 与 Tunnel 客户端），不再只修登录一条链路。
- TLS 校验策略未被放宽：仍为 `CERT_REQUIRED` 且保留主机名校验；只在确实缺少根证书时
  补充信任来源。证书链仍不可信时，错误信息会给出可执行的下一步（安装代理根证书，
  或改用 `auth login --from-env`、AK/SK、外部凭据 provider）。
- 安装器契约与发布归档的端到端测试在受终端管控的环境下不再无限等待，改为显式跳过并
  说明原因。

### Compatibility

- 无默认行为回退：仅在检测到企业 CA 时才合并信任库，普通环境结果不变。
- 合并出的临时 bundle 权限为 `0600`，仅当前用户可读。

## [0.6.1] — 2026-09-20

### Fixes

- `query` / `job result` 读取结果时，若服务端返回的文本无法被 CSV 解析器按列
  cast（典型场景：`SHOW INDEXES` 返回含未加引号逗号的结果文本），不再报
  `list index out of range` 并误判为连接故障。作业本身成功时降级返回原始任务
  结果：行落在 `result` 列（附 `task_name` 列），`metadata.result_kind` 为
  `raw_task_result`，并在 `agent_hints.warnings` 中说明未做类型转换。无原始
  结果可降级时保持原有错误翻译不变。
- 受影响命令示例：`aliyun maxc query "SHOW INDEXES ON <project>.<schema>.<table>"`。

### Compatibility

- 正常可解析结果的行为不变；实例 Tunnel 路径不经该解析器，不受影响。
- 降级结果是字符串原文而非结构化列，消费方应按 `result_kind` 判别后再解析。

## [0.6.0] — 2026-09-18

### Features

- 新增账号级 `semantic` 语义包远程管理命令组：版本化 JSON 导出、经审阅的
  diff/apply（带草稿修订保护）与发布校验。
- Catalog 请求签名保留不透明分页 token 与查询保留字符；认证失败与权限拒绝
  区分为不同错误码。

### Security and Reliability

- 本地 `meta semantic` 注解与远程语义包相互独立。
- 拒绝过期计划、不安全文件路径，以及对结果不确定写入的自动重试。

## [0.5.4] — 2026-09-17

### Fixes

- 为代理登录增加 `--odps-endpoint` 与 `--odps-region` 别名，避免 Alibaba Cloud
  CLI wrapper 吞掉 MaxC 路由参数。使用 `aliyun maxc` 时优先采用新别名，独立
  入口的旧别名继续保留。

## [0.5.3] — 2026-09-17

### Features

- 新增显式 `auth login-proxy`，用于可信凭据注入出口：只保存路由配置，忽略
  本机凭证，发送不带冲突鉴权头的未签名 ODPS 请求。

### Security and Reliability

- 保留在线身份校验、原子登录替换、仅本地的 context/manifest 行为与既有签名模式。

## [0.5.2] — 2026-09-01

### Features

- 公开 `query --force` 与 `job submit --force`：在用户明确授权且 project、schema、
  目标与影响均已核对的前提下，允许执行一条精确的 DDL/DML。默认仍只接受可证明
  为只读的 SQL。

### Security and Reliability

- `--force` 只放行一条可识别的 DDL/DML，继续拒绝多语句、过程脚本、权限与账号
  管理、资源包管理和未知操作（含带数据面前缀的 `CHANGE OWNER` 和授权/标签子句）。
  MaxCompute raw string 统一识别，字符串内的引号或分号不再干扰单语句判断，也不
  能用于隐藏第二条写操作。报错、dry-run、cost、explain 或建议动作本身不构成写入
  授权，写 SQL 的分析结果不会生成自动重放动作。
- 支持 `CREATE OR REPLACE TABLE` 与 `LOAD INTO/OVERWRITE TABLE`；对未证实的
  `LOAD DATA` 语法失败关闭。
- Envelope、纯文本、流式事件与审计记录中的 LogView 统一去除签名查询参数、
  fragment 与 URL userinfo；无法解析的 authority 失败关闭为固定脱敏占位符，
  避免临时访问令牌进入日志或最终回答。
- `query` / `job` 响应中的 `safety.effective_hints` 反映实际发送给 MaxCompute 的
  执行参数；只读兼容模式下未知 hint 与已审查 key 上的异常值统一脱敏。
- 公共 Skill 与运行时契约同步：要求 Alibaba Cloud CLI 3.3.19+，云 API 调用复用
  session User-Agent，明确本地 context/manifest 语义、异步结果复用与原子输出
  覆盖规则。

## [0.5.1] — 2026-08-31

### Fixes

- 修复多个进程首次初始化同一状态目录时的创建竞态；并发创建不再误报 `FileExistsError`。
- 隔离只读 SQL 门禁的 CLI 回归测试，确保 Linux、Windows 和 Python 版本矩阵得到一致结果。

## [0.5.0] — 2026-08-31

### Breaking Changes

- 自动发现的工作区配置不再允许定义 `auth`；凭证必须位于用户级 `~/.maxc/config.yaml` 或显式 `--config`。
- `data upload` 不再隐式创建缺失分区；必须显式传入 `--create-partition`。
- 远程查询不再接受会造成重复提交歧义的自动重试参数；异步恢复统一使用 `job_id` 和 cursor。
- `agent_hints.next_actions` 只包含无需补参、无需确认且允许 Agent 自动执行的命令。

### Features

- 新增由实时 parser 生成的 `agent manifest`，覆盖全部命令的参数、副作用和输出形状。
- OAuth 登录、刷新采用可恢复的结构化 Envelope；`agent context` 保持纯本地，`agent doctor --online` 才执行在线验证。
- Job 失败状态、等待流和结果读取统一返回可恢复的类型化错误；query/job cursor 绑定 SQL、project 和 session。
- 查询超过同步等待预算时返回可直接执行的 `job result --max-rows ...` 动作。
- Upload 在创建 Tunnel session 前完成整文件校验；失败区分 commit 未尝试与 commit 结果未知。
- 本地 metadata FTS 索引可重建且可在无 FTS5 的 SQLite 上降级运行。

### Security and Reliability

- 配置、OAuth、Job store、cache 和 audit 使用 owner-only、原子替换及跨进程锁。
- 外部凭据 helper 以 argv + `shell=false` 执行；审计日志递归清除凭据和 SQL 原文。
- SQL 执行采用 SELECT-only 正向允许列表，未知操作 fail closed。
- Markdown/brief 只把可执行、允许 Agent 且无需确认的 action 展示为下一步。

## [0.4.2] — 2026-06-02

- `job submit --dry-run`：预估 SQL 成本而不实际提交。
- `data upload --dry-run`：校验表结构和 CSV 文件而不上传数据。

## [0.4.1] — 2026-06-02

- 统一设置 UserAgent，所有 ODPS 请求携带 `maxc-cli/{version}` 前缀。

## [0.4.0] — 2026-06-01

- `--help` 输出格式全面改为 aliyun CLI 风格。
- Agent skill 安装目录统一为 `alibabacloud-maxcompute-cli`。
- `MAXC_CLI_NAME` 环境变量控制 help/version/SKILL 模板中的程序名。

## [0.3.1] — 2026-05-25

- `agent skill` 六动词子命令：`install`、`update`、`uninstall`、`list`、`diff`、`path`。
- 平台注册表支持 claude-code、cursor、windsurf、codex、qwen、qoder、qoderwork。
- 全局 flag 位置无关；auth 自动重定向；NCS auth flow。

## [0.2.4] — 2026-05-09

- `data upload` / `data download`：CSV/TSV 批量导入导出（Tunnel API）。

## [0.2.1] — 2026-04-22

- Catalog API 集成：交互式项目选择器。
- 外部凭证进程支持。
- `meta semantic set/get/list-missing`：语义元数据。
- `agent install-skill`：一键注册 SKILL 到各平台。
- `query --wait` 替代旧 `--async/--timeout`。
