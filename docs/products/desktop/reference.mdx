本页汇总功能速查表、系统要求、常用快捷键与设置项，便于快速查找能力入口和默认配置。

## 功能速查

| 功能类别  | 功能项                                                                           |
| --------- | -------------------------------------------------------------------------------- |
| 连接管理  | 多地域多项目连接、AccessKey 认证、连接测试、标题栏数据源切换                     |
| SQL 开发  | 语法高亮、智能补全、格式化、多文件管理、版本历史、查询历史                       |
| 数据管理  | Catalog 浏览、数据预览、分区管理、结构化导入（CSV / Excel / Parquet）、Blob 导入 |
| 结果分析  | 表格、20 种图表、透视表、数据质量、Logview；导出 CSV / JSON / Parquet / XLSX     |
| 表洞察    | 画像、质量、离群、走势、变化、归因、漂移、相关、存储建议（Beta）                 |
| 数据看板  | Pin 成盘、磁贴布局、TTL 缓存、点击联动、下钻、定时刷新、JSON / PNG 导出、AI 成盘 |
| AI 探索   | Agent 与专家模式、@表名引用、斜杠技能、计划审批、执行追踪、语音播报、多会话      |
| AIGC 创作 | 影视工程（剧本到成片）、音乐工程、PPT 演示文稿                                   |
| 知识智能  | SQL 片段知识库、语义包、跨会话记忆                                               |
| 多模态    | Blob 浏览与预览、WebDAV 只读挂载、MixCompute 编排                                |
| 生态      | 多数据源、OSS 文件管理、dbt、办公协作、定时任务、MCP、OpenClaw                   |

## 系统要求

| 操作系统 | 版本要求    | 说明                                          |
| -------- | ----------- | --------------------------------------------- |
| macOS    | 12.3 及以上 | Apple Silicon 原生，Intel 通过 Rosetta 2 转译 |
| Windows  | 10 及以上   | 64 位                                         |

## 设置项

单击标题栏右侧的**齿轮**图标打开设置对话框。设置按标签页组织，以下为主要配置项。

### 编辑器

| 配置项     | 说明                | 默认值 |
| ---------- | ------------------- | ------ |
| 字体大小   | SQL 编辑器字号      | 14px   |
| Tab 大小   | 缩进宽度            | 4      |
| Minimap    | 是否显示代码缩略图  | 开启   |
| 自动换行   | 长行是否折行        | 开启   |
| UDF Studio | 侧边栏 UDF 开发入口 | 开启   |

### AI 配置

| 配置项   | 说明              | 默认值         |
| -------- | ----------------- | -------------- |
| API URL  | AI 服务地址       | 阿里云百炼     |
| API Key  | AI 服务的 API Key | 无，需自行创建 |
| 模型名称 | 使用的模型 ID     | 推荐模型       |

AI 高级配置提供上下文长度、最大步数、Temperature、步骤超时、最大并行工具数、会话历史大小、推理档位等参数，一般保持默认即可。

### 语音交互

配置语音播报的模型与音色。任务完成后可将 AI 的最终结论朗读出来，功能为可选开关。

### 工具与技能管理

- **工具管理**：查看并按需启用 / 停用 AI Agent 可调用的工具。
- **Skills**：浏览内置技能清单，配合会话中的斜杠命令使用。

### Beta 功能开关

部分功能需启用对应开关后，活动栏才显示入口：

| 功能       | 默认 | 开关位置        | 开启后入口                 |
| ---------- | ---- | --------------- | -------------------------- |
| Blob 存储  | 关   | 设置 ▸ 多模态   | 多模态组 · Blob 多模态存储 |
| 语义包     | 关   | 设置 ▸ Beta     | 智能组 · 语义包            |
| dbt 集成   | 开   | 设置 ▸ 生态接入 | 生态组 · dbt 项目          |
| 协作办公   | 开   | 设置 ▸ 生态接入 | 生态组 · 办公协作          |
| MixCompute | 关   | 设置 ▸ 多模态   | 多模态组 · MIXCOMPUTE      |

数据看板、查询历史、知识搜索等核心功能不受 Beta 开关控制。

### 主题与语言

单击标题栏主题图标切换深色 / 浅色主题，即时生效。界面支持中文和英文。

### 版本与诊断

- **检查更新**：发现新版本时标题栏出现**更新**按钮，一键完成升级。
- **诊断日志导出**：把前后端运行日志打包为 `.zip`，排查问题时提供给支持团队。
