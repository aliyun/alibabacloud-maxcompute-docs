本页介绍 MaxCompute AI数据探索的安装、更新与卸载。

## 系统要求

| 操作系统 | 版本要求    | 说明                                                         |
| -------- | ----------- | ------------------------------------------------------------ |
| macOS    | 12.3 及以上 | 为 Apple Silicon 原生编译，Intel 芯片通过 Rosetta 2 自动转译 |
| Windows  | 10 及以上   | 支持 64 位系统                                               |

## 安装

### macOS

1. 下载 [MaxCompute_aarch64.dmg](https://maxquery-updates.oss-cn-hangzhou.aliyuncs.com/maxquery-studio/latest/MaxCompute_aarch64.dmg)。
2. 打开 DMG 文件，将应用图标拖入 Applications 文件夹。
3. 双击启动应用。

正式发布包已通过 Apple 开发者签名与公证，首次启动可直接运行。如果使用的是未签名内测包并提示「无法验证开发者」或「应用已损坏」，在终端执行以下命令后重启应用：

```bash
sudo xattr -rd com.apple.quarantine "/Applications/MaxQuery Studio.app"
```

### Windows

1. 下载 [MaxCompute_x64_zh-CN.msi](https://maxquery-updates.oss-cn-hangzhou.aliyuncs.com/maxquery-studio/latest/MaxCompute_x64_zh-CN.msi)，双击并按引导完成安装。
2. 在开始菜单或桌面双击应用图标启动。

### 验证安装

启动后主界面正常加载，且标题栏显示当前版本号，即安装成功。可在**设置 ▸ 关于**中查看客户端版本并运行服务健康检查。

## 更新

客户端内置自动更新：

1. 发现新版本时，标题栏出现**更新**按钮。
2. 单击**更新**，客户端自动下载并重启完成升级，无需手动下载安装包。

也可以在**设置 ▸ 关于**中加入**抢先体验计划**，提前获取新功能。

## 卸载

- **macOS**：将 Applications 中的应用拖入废纸篓。
- **Windows**：在系统设置的「应用」列表中卸载。

卸载仅移除应用文件。SQL 脚本、连接配置、查询历史等用户数据保存在用户目录下，如需彻底清理可一并删除。
