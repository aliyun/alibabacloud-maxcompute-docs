本页介绍 MaxCompute Desktop 的安装、更新与卸载流程。

## 获取产品

选择下载渠道时，请同时确认版本信息和完整性验证方式。

## 安装

安装步骤将按操作系统组织，并说明系统要求、权限、安装位置和验证方法。

## 更新

更新前，请确认兼容性、配置保留范围和数据备份要求。

## 卸载

卸载时请确认应用文件、用户配置、缓存和本地数据的处理范围。
