客户端支持同时保存多个 MaxCompute 连接，覆盖生产、测试、开发环境以及不同地域和租户，切换时无需重复输入认证信息。

## 适用场景

- 在多个项目之间切换提交作业。
- 同一项目使用不同账号权限验证数据可见性。
- 跨地域管理多套 MaxCompute 项目。

## 新建连接

1. 在左侧活动栏**工作室**组中，单击**连接**图标（插头形状）。
2. 单击面板顶部的 **+**，打开新建连接对话框。
3. 填写连接名称、鉴权方式、区域、项目名称和认证信息。区域选定后 Endpoint 自动填充；鉴权方式切换时表单字段随之变化。
4. 单击**测试连接**验证配置。
5. 单击**保存并连接**完成创建。

> **说明**
> 尚未创建任何连接时，主界面中央会显示**添加连接**按钮，单击后进入同一流程。

## AKless（NCS）鉴权

客户端内置 NCS AKless 鉴权，无需安装单独的鉴权插件：

1. 新建连接时在**鉴权方式**中选择**AKless 鉴权**。
2. 填写 Endpoint、项目名称并选择登录账号。

本机需要已安装 NCS 命令行工具并完成登录；账号加载失败时，账号选择器会说明原因，处理后重试即可。升级客户端后原有 AKless 连接和凭据保留，无需重建。

## 支持的地域

客户端支持阿里云 MaxCompute 公共服务地域，覆盖中国大陆主要地域（含金融云、政务云）与海外地域（新加坡、日本、德国、美国等）。专有环境可选择**自定义 Endpoint**，手动填写服务地址。

## 连接测试失败排查

测试失败时依次检查：

1. Endpoint 是否与项目所在地域匹配。
2. AccessKey 是否正确且未过期。
3. 本机网络是否可访问对应地域。
4. AccessKey 对应账号是否具备该项目的访问权限。

仍无法解决时，收集**设置 ▸ 关于**中的诊断日志并提供给支持团队。

## 多连接管理与切换

- **切换连接**：在连接面板单击目标连接，或在标题栏**数据源切换器**中快速切换。后续 SQL 执行、Catalog 浏览、数据导入均在当前活动连接上进行。
- **连接 / 断开**：在连接条目上单击对应操作。
- **删除连接**：单击删除图标移除。修改配置时删除后重建即可。

连接面板支持按国家 / 地区筛选，适合管理较多连接的用户。
