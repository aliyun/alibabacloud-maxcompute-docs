MaxCompute 支持在表中通过 Blob 类型存储图片、视频、音频、PDF、Office 文档等非结构化数据。客户端在此之上提供文件管理式的操作体验：文件浏览器、多格式预览、上传下载、WebDAV 本机挂载，以及 MixCompute 可视化编排多模态计算。

## 功能概述

| 能力                | 说明                                                                       |
| ------------------- | -------------------------------------------------------------------------- |
| Blob 文件浏览器     | 以文件管理器样式浏览 `fs_` 前缀的 Blob 存储表，网格 / 列表视图、面包屑导航 |
| 多模态预览          | 图片、视频音频、PDF、Office 文档、文本与二进制 HEX 预览                    |
| 上传与下载          | 工具栏上传、拖拽上传、单个与批量下载                                       |
| WebDAV 挂载         | 把 Blob 表挂载为本机只读文件夹                                             |
| MixCompute 多混计算 | 拖拽算子编排流水线，处理 Blob 列数据                                       |

![多模态数据处理架构](./assets/multimodal-blob.svg)

## 前提条件

- 已创建并成功连接一个 MaxCompute 数据源。
- Blob 相关功能为 Beta，默认关闭。在 设置 ▸ 多模态 中开启 **Blob 存储**开关后，侧边栏**多模态**分组出现 **Blob多模态存储**入口，WebDAV 只读服务同时启动。
- MixCompute 需在 设置 ▸ 多模态 中单独开启 **MixCompute** 开关（Beta，默认关闭），开启后**多模态**分组出现 **MIXCOMPUTE** 入口。

**Blob 存储**开关下方可配置本地缓存：

| 设置项            | 说明                                            | 默认值    |
| ----------------- | ----------------------------------------------- | --------- |
| Blob 文件缓存时间 | 本地磁盘缓存的有效时间（小时），设为 0 禁用缓存 | 12 小时   |
| Blob 缓存大小     | 缓存占用的磁盘空间上限                          | 最大 2 GB |
| 清空缓存          | 手动清除所有已缓存的 Blob 文件和缩略图          | —         |

## Blob 文件浏览器

入口：侧边栏 ▸ **多模态** ▸ **Blob多模态存储**。文件浏览器展示当前项目中 `fs_*` 文件存储表的目录结构：

| 操作            | 说明                                                             |
| --------------- | ---------------------------------------------------------------- |
| 网格 / 列表视图 | 单击切换文件展示方式                                             |
| 面包屑导航      | 单击路径中的任意层级快速跳转                                     |
| 上传            | 单击工具栏的上传按钮选择本地文件，或将文件直接拖入文件浏览器区域 |
| 查看与预览      | 单击文件打开预览标签页，查看文件内容                             |
| 下载            | 单击文件的下载按钮保存到本地，也支持选中多个文件批量下载         |

## 多模态预览

在文件浏览器中单击文件，或在查询结果表中单击 Blob 单元格的预览按钮，均会打开独立的预览标签页。支持的预览格式：

| 格式类别 | 支持的类型                                    |
| -------- | --------------------------------------------- |
| 图片     | JPEG、PNG、GIF、WebP、BMP、TIFF               |
| 视频     | MP4、WebM、MPEG                               |
| 音频     | WAV、MP3、OGG、FLAC                           |
| 文档     | PDF、Word（docx）、Excel（xlsx）、PPT（pptx） |
| 文本     | JSON、XML、CSV、TSV、Markdown、纯文本         |
| 二进制   | HEX 十六进制查看                              |

预览标签页支持切换预览模式（自动检测、图片、视频、音频、文档、文本、HEX），适用于文件类型未知或需要换一种方式查看的场景。

SQL 查询返回包含 Blob 列的结果时，结果面板自动提供缩略图展示（文件类型图标或图片缩略图）、单元格下载与列批量下载。

## WebDAV 只读挂载

客户端在本地启动一个只读 WebDAV 服务，允许通过系统文件管理器直接浏览 MaxCompute 中的文件。macOS 连接方式：

1. 在 Finder 中按 **⌘K**（前往 ▸ 连接服务器）。
2. 输入地址 `http://127.0.0.1:8899/dav/`（可在设置页复制）。
3. 单击**连接**，即可像本地文件夹一样浏览和下载文件。

> **重要**
> WebDAV 仅支持只读操作（浏览和下载），不支持写入；仅限本机访问（127.0.0.1），不对外暴露；关闭客户端后 WebDAV 服务停止，连接自动断开。

## MixCompute 多混计算

启用 Beta **MixCompute** 后，在 **MIXCOMPUTE** 画布中以拖拽方式对 Blob 列编排 Python UDF 算子流水线（DAG）：

选择数据源与目标列 → 拖拽算子 → 连接端口 → 配置参数 → 预览 SQL → 发布执行。
