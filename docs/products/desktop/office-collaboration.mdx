办公协作模块把飞书文档生态与 MaxCompute 数据平台衔接起来：可将飞书云盘文件、知识库文档、在线表格中的数据导入 MaxCompute 表进行离线分析，也可将 MaxCompute 查询结果分享为飞书在线表格，便于团队协作。

## 适用场景

- **结构化数据归档**：团队在飞书在线表格中维护签到、报名、货单等数据，需要归档到 MaxCompute 进行离线关联分析。
- **查询结果分享**：MaxCompute 中的计算结果需要发布为飞书在线表格，通过链接分享给没有 MaxCompute 权限的协作方。
- **非结构化文档处理**：飞书云盘中沉淀的 PDF、DOC、PPT 等办公文件，需要导入 MaxCompute 做批量文本提取、OCR、翻译等加工处理。

## 功能概述

客户端通过飞书 Open API 读取用户有权限访问的文档资源，支持把结构化数据（在线表格、多维表格）与非结构化内容（文档、附件）导入 MaxCompute，同时支持把查询结果反向分享到飞书；文档浏览覆盖知识库、云盘与文档搜索，连接管理覆盖应用绑定、OAuth 授权、权限诊断与断开连接。

## 启用开关与连接器

办公协作功能由设置开关控制，默认开启：

1. 打开**设置 ▸ 生态接入 ▸ 办公协作**。
2. 开启**启用协作办公**开关后，侧边栏显示**办公协作**模块（链接图标）。

协作面板提供飞书、钉钉、Notion 连接器：当前飞书可用，钉钉与 Notion 标注「即将支持」。

## 配置飞书应用

使用飞书集成前，完成以下准备：

1. 访问[飞书开发者后台](https://open.feishu.cn/app)，单击**创建企业自建应用**，填写应用名称和描述。
2. 在**凭证与基础信息**页面获取 **App ID** 和 **App Secret**，并填写到**设置 ▸ 生态接入 ▸ 办公协作**。
3. 在**权限管理**页面开通以下权限：

   | 权限                        | 用途             |
   | --------------------------- | ---------------- |
   | drive:drive:readonly        | 浏览云盘文件列表 |
   | wiki:wiki:readonly          | 浏览知识库       |
   | docx:document:readonly      | 读取在线文档内容 |
   | sheets:spreadsheet:readonly | 读取在线表格数据 |
   | bitable:app:readonly        | 读取多维表格数据 |
   | drive:export:readonly       | 导出文档内容     |

完成权限开通后，在**版本管理与发布**页面发布应用；个人版飞书的应用修改后自动发布。

> **说明**
> 应用只能访问自身创建的文档、明确与应用共享的文档，以及应用被添加为协作者的知识库。如需访问更多文档，请在飞书中将应用添加为目标文档或知识库的协作者。

## 连接飞书

1. 在侧边栏单击**办公协作**图标，打开协作面板。
2. 单击**飞书**连接器进入飞书功能区。
3. 单击**飞书授权登录**；若提示「未配置 App ID/App Secret」，先在设置页完成应用配置。
4. 浏览器弹出飞书授权页面，确认授权后返回客户端。
5. 授权成功后显示当前登录的飞书用户名，面板切换到文档浏览模式。

绑定成功后自动执行权限诊断，依次检查 Token 获取、Wiki 知识库、云盘文件、文档搜索四项；全部通过后进入文档浏览器，某项失败时请检查对应权限是否已在飞书开发者后台开通。在飞书功能区单击**断开连接**可清除本地授权凭证，断开后需重新授权才能使用飞书功能。

## 浏览飞书文档

文档浏览器展示两个根节点：**知识库 Wiki**（应用可访问的 Wiki 空间与子节点）和**云盘 Drive**（云盘中的文件夹与文件）。

| 类型                | 说明                           |
| ------------------- | ------------------------------ |
| 在线文档（docx）    | 飞书在线文档，导入后转为文本块 |
| 在线表格（sheet）   | 飞书在线表格，导入后保留列结构 |
| 多维表格（bitable） | 飞书多维表格，导入后转为记录   |
| 文件夹（folder）    | 可展开浏览子节点               |
| 附件（file）        | PDF、DOC、PPT、图片等文件      |

## 导入飞书数据到 MaxCompute

导入分**文件导入**与**表格导入**两种模式。

### 文件导入

适用于在线文档与云盘附件，把文档内容导入 MaxCompute 表，用于后续文本加工处理：

1. 在文档浏览器中勾选需要导入的文档。
2. 顶部显示已选数量，单击**同步配置**。
3. 填写任务名称和表名前缀（默认 `feishu_`）。
4. 单击**开始同步**。

### 表格导入

适用于在线表格与多维表格，以结构化方式导入并保留列名和数据类型：

1. 在文档浏览器中勾选目标表格，切换到**表格导入**模式。
2. 预览表格结构和数据样本。
3. 确认列映射后单击**开始同步**。

同步任务为异步执行，创建后可在任务列表中查看进度；任务完成后数据写入 MaxCompute 表，可通过 SQL 查询。

## 分享查询结果到飞书

1. 执行一条查询，等待结果返回。
2. 在结果面板工具栏单击**分享到飞书**。
3. 客户端在飞书中创建一份新的在线表格，写入列名和数据行。
4. 分享完成后提示「已分享到飞书，点击打开」，单击可跳转到飞书表格页面。

> **说明**
> 分享前需已完成飞书授权；分享的表格创建在当前授权用户的飞书云盘中。
