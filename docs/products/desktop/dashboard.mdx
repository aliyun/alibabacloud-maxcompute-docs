数据看板把常用 SQL 查询固化为可视化磁贴，组成一张可定时刷新、全局过滤、多图联动的看板，免去每天重复执行相同查询。

## 适用场景

- **每日大盘与周期报表**：把核心指标查询固化为看板，配置每天 08:00 定时刷新，早会打开即看；在 AI Query 中完成分析后，把结论图表 Pin 到看板并配置定时刷新，形成自动更新的周期性报表，或导出 PNG 长图与 JSON 规格分享。
- **多维度切片分析**：通过全局过滤器在区域、渠道、时间等维度间切换，所有图表同步响应。
- **异常定位**：在总览图表上发现异常点后，单击触发联动缩小范围，下钻到行级明细。

## 功能概述

看板由多个磁贴组成，每个磁贴对应一条 SQL 查询和一种可视化方式。磁贴的查询结果按 TTL 缓存，支持定时后台刷新，打开看板时直接展示缓存结果；全局过滤器可一次切换所有磁贴的筛选条件，图表之间支持点击联动与下钻明细。看板可由查询结果 Pin、AI 自然语言建盘、手动搭建或导入规格创建，磁贴数据统一来自 MaxCompute SQL 查询。

## 前提条件

- 已创建并成功连接一个 MaxCompute 数据源。磁贴执行 SQL 时使用看板绑定的连接。

## 快速入门

1. 在编辑器中执行一条 SQL，切换到图表视图，调整好图表类型和坐标轴。
2. 单击图表区域的**Pin 到看板**，选择**新建看板**并填写名称。
3. 看板自动打开，SQL、图表配置和连接信息随磁贴一并带入。先在查询中把图调对，再 Pin 固化，这是推荐的建盘方式。

## 看板布局与编辑

### 编辑模式

看板分**预览**与**编辑**两种模式。单击工具栏的**编辑**进入编辑模式，此时可以拖拽磁贴调整位置和大小（基于网格布局）、添加删除和配置磁贴、添加和编辑全局过滤器。编辑基于工作副本，保存前不影响其他查看者；单击**保存**提交修改，单击**取消**丢弃改动。

### 从零搭建看板

1. 在侧边栏**数据看板**面板单击**新建**，看板自动打开。
2. 单击工具栏的**编辑**进入编辑模式。
3. 单击**添加磁贴**，选择磁贴类型，在配置面板填写 SQL，拖拽调整布局后单击**保存**。

## 磁贴类型

| 类型          | 用途                   | 说明                                                       |
| ------------- | ---------------------- | ---------------------------------------------------------- |
| 图表          | 趋势、占比、对比、分布 | 支持多种图表类型，编辑模式下可通过配置面板切换             |
| 表格          | 明细数据展示           | 原样展示查询结果的列和行                                   |
| 指标卡（KPI） | 单个核心数字           | 支持求和、平均、最小、最大、计数、首行聚合，可配单位与格式 |
| 文本          | 标题、说明             | 支持 Markdown                                              |

支持的图表类型：柱状图、折线图、面积图、组合图、饼图、环形图、散点图、气泡图、水平柱状图、雷达图、直方图、箱线图、瀑布图、桑基图、树图、漏斗图、二维热力图、3D 柱状图、3D 散点图、3D 曲面图、3D 热力图、KPI 迷你趋势线。编辑模式下选中磁贴打开配置面板，可设置**标题**、**SQL**、**连接**（默认继承看板连接，可单独指定）、**缓存 TTL**（有效期，默认 1 小时）、图表类型与 X/Y 轴字段；指标卡可配置值列、聚合方式、单位与格式。

## 全局过滤器

编辑模式下单击**添加过滤器**，过滤器出现在看板顶部，预览模式下可随时调整。

### 过滤器类型

| 类型     | 场景           | 说明                                                        |
| -------- | -------------- | ----------------------------------------------------------- |
| 时间范围 | 按日期筛选     | 支持近 7 天 / 30 天 / 90 天预设，绑定分区列时下推为分区裁剪 |
| 单选     | 切换区域、渠道 | 候选值自动从磁贴结果 distinct 获取                          |
| 多选     | 同时看多个类目 | 勾选式弹层                                                  |
| 文本     | 模糊搜索       | LIKE 匹配                                                   |
| SQL 条件 | 自定义谓词     | 原样合入 WHERE，带启用/停用开关                             |
| 参数     | 可调控件       | `{{param:name}}` 占位符替换为数值、日期、枚举               |

### 过滤器作用方式

- **服务端过滤**（推荐）：磁贴 SQL 中写 `{{filters}}` 占位符，过滤条件注入 SQL 重新查询；时间范围绑定分区列时直接分区裁剪。
- **客户端过滤**：SQL 无占位符时，过滤在已加载的结果行上执行，不重新查询，适合小结果集。

## 联动与下钻

### 点击联动

- 预览模式下单击任意图表的数据点（如柱状图的某根柱）后，顶部出现联动标签，显示来源磁贴和维度值。
- 其他包含相同列的磁贴自动过滤到该值，源图表自身保留全貌；再次单击同一数据点取消联动。联动为客户端行为，瞬时生效，不触发重新查询。

### 下钻明细

在磁贴配置中单击**添加下钻**，填写一条明细 SQL，用 `:value` 或 `:列名` 占位符代入单击的数据值。预览模式下单击图表数据点后，磁贴菜单出现**查看明细**，弹层展示明细查询结果：

```sql
SELECT * FROM dwd_order_detail
WHERE region = :value AND ds >= '20260101'
LIMIT 100
```

## 刷新与缓存

### 缓存机制

- 每个磁贴的结果按 TTL 缓存，默认 1 小时；打开看板时命中缓存直接展示，过期才重新查询，不同过滤条件的结果分开缓存。单击磁贴的**刷新**按钮强制重查单个磁贴，工具栏**刷新全部**强制刷新全部磁贴；磁贴菜单中可单击**打开 Logview**，在浏览器中查看作业执行详情，排查慢查询和资源消耗。

### 定时刷新

工具栏单击**定时刷新**打开配置弹层：

| 频率   | 说明                       |
| ------ | -------------------------- |
| 每小时 | 指定在每小时的第几分钟执行 |
| 每天   | 指定时间执行（如 08:00）   |
| 工作日 | 周一至周五指定时间执行     |
| 每周   | 选择星期几并指定时间       |

定时刷新到点后在后台自动重查所有磁贴并写入缓存，即使看板标签页未打开，下次打开直接命中新数据。后台刷新完成后弹出可单击的 Toast，可直接跳转到看板；桌面端可按看板开启**刷新完成系统通知**（定时刷新配置弹层中的开关），应用在后台也能收到系统通知。看板列表每行显示上次刷新时间，有失败磁贴时显示失败角标。

> **说明**
> 定时刷新仅在应用运行期间生效，应用未运行时不会补跑。

## 将查询结果加入看板

- **从 SQL 编辑器 Pin**：执行 SQL 后切换到图表视图，调整图表类型和配置，单击图表区域的**Pin 到看板**，在对话框中选择目标看板（已有或新建）并确认，磁贴带着 SQL、图表配置和连接信息加入目标看板。
- **从 AI Query Pin**：AI Query 对话中产出的图表同样支持 Pin，单击图表上的**Pin 到看板**，流程与 SQL 编辑器一致。
- **通过 AI 创建**：在 AI Query 对话中用自然语言下达指令，例如「帮我建一个销售大盘看板，包含日订单量趋势和区域分布饼图」创建看板、「往销售看板里加一个退款率折线图」追加磁贴、「刷新销售看板的所有数据」刷新数据。

## 看板管理

侧边栏**数据看板**面板展示所有看板，每行显示名称、磁贴数、更新时间、刷新状态，悬停出现**重命名**、**复制**、**删除**操作。删除的看板先移入底部**已归档**折叠区，数据不丢失，可随时**恢复看板**回到活跃列表；彻底删除需在归档区再次确认。已归档的看板不出现在 Pin 目标列表中。

| 方式             | 产物                   | 用途                   |
| ---------------- | ---------------------- | ---------------------- |
| 导出 PNG 图片    | 整盘长图（2 倍清晰度） | 发群、贴周报、汇报截图 |
| 导出规格（JSON） | 看板完整定义           | 备份、给同事复刻看板   |

导出通过工具栏**导出**菜单完成。在列表面板顶部单击**导入规格**（JSON）即可复刻看板；若规格引用了本机不存在的连接，会提示在编辑模式重新指定。
