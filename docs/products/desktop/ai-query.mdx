AI Query 是客户端右侧的数据分析面板：您用自然语言提问，Agent 把业务问题拆解为带证据链的多步分析，在 MaxCompute 上规划、执行并输出结论。本页说明如何提问、控制执行过程并验收结果。

## 适用场景

| 场景           | 示例提问                                           |
| -------------- | -------------------------------------------------- |
| 快速元数据问答 | 「查看当前项目有哪些表」「查看 orders 表结构」     |
| 多步分析洞察   | 广告 ROI 归因、存储治理 Top-N 分析                 |
| SQL 片段执行   | 「执行 SQL 片段：存储减少分析，日期改为最近 3 天」 |
| SQL 优化与诊断 | 「优化当前 SQL」「执行报错了帮我看看」             |

## 打开面板

单击标题栏右侧的 **AI** 按钮展开面板，再次单击收起。面板顶部提供两个 Tab：

- **AI Query**：本页所述的数据分析 Agent。
- **AI Coding**：面向代码编辑的副驾，用于编写 UDF 与 SQL 代码。

面板头部提供**会话历史**、**新建会话**与**全屏展开**操作，单击**全屏展开**进入 Quest 全屏布局，面板宽度可拖拽调整。关闭面板后，会话在后台继续运行。

输入框工具栏的模式选择器提供 **Agent**（默认，多步任务执行）与**专家模式**（深度分析）两种模式，深度分析见[专家模式](./expert-mode.mdx)。

## 输入能力

### 引用表

在输入框输入 `@` 触发表引用：客户端先在本地 Catalog 中匹配，命中不足时对当前连接发起远端检索。选中表后自动把表结构提供给 Agent，并在输入框上方生成可移除的表引用标签。

### 调用技能

在输入框输入 `/` 弹出技能与命令面板，分为 Skills、Commands、Tools 三组：

- 激活编排类技能后，下一轮对话生效。
- 内置 `/compact` 命令可压缩当前会话上下文。
- 面板中还提供推理档位（Fast / Balanced / Max）与 **Thinking** 开关。

### 语义域与文件附件

- **语义域选择器**：在 Agent 与专家模式下可多选语义包，为 Agent 提供业务口径上下文。
- **文件附件**：单击附件按钮或拖拽文件到输入区，文件信息随请求提供给 Agent。

## 执行流程

一次完整的分析按以下步骤进行：

1. **规划**：Agent 生成执行计划，以步骤列表展示，每步标注将使用的能力。
2. **审批**：查看计划后**批准**启动；也可先**修订计划**再继续。
3. **执行**：Agent 逐步执行，每步的参数、状态与结果实时展示为工具调用卡片。执行中可输入引导意见影响下一步决策；写文件、DDL 等高风险操作会弹出确认卡片。
4. **计划编辑**：暂停后可对未执行步骤跳过、插入或重排，再恢复执行。
5. **总结与验收**：完成后输出结论；验收阶段可提交修订意见，或拒绝并要求重新规划。
6. **停止**：思考中可单击红色**停止**按钮中断，被停止的消息标记为「已停止」。

Agent 的执行产物（查询结果、图表配置、分析报告、执行计划快照）保存在会话工作区，可在资源管理器面板的 **AI Workspace** 文件树中查看。

## 报错提示与执行追踪

- 执行出错时展示失败诊断卡，包含**错误码**、**错误类型**与**修复建议**；被拦截的 SQL 以琥珀色标注并给出原因分类（如 SQL 语法拦截）。
- 执行追踪展示每步的工具名、参数、状态、结果与耗时，实时更新，重载会话后保持一致。

## 语音播报

任务完成时可将最终结论朗读出来，最长约 500 字。语音播报为可选开关，默认模型 `qwen3-tts-flash`，默认音色 `Cherry`，可选用其他语音模型与音色（纯英文音色仅支持英文播报）。被中断的运行不播报，后台会话保持静默。

## 多会话并发

多个会话可并发运行：切换会话时，后台会话继续执行并推送结果；非当前 Tab 的会话仍在运行时，该 Tab 显示绿色脉冲点。会话内容本地持久化，重启客户端后可恢复。

## 内置能力

Agent 可调用的主要能力如下，实际以运行时技能目录为准：

| 能力       | 说明                                         |
| ---------- | -------------------------------------------- |
| 元数据探查 | 列出表、批量获取表结构、获取分区、获取表统计 |
| 执行查询   | 执行 SQL，自动注入行数限制                   |
| SQL 知识库 | 搜索知识库模板，改写日期后执行               |
| 图表与报告 | 生成图表、保存分析报告                       |
| 看板管理   | 用自然语言创建和修改数据看板                 |
| 联网信息   | 网页抓取与网页搜索                           |
| 文件操作   | 读写本地文件，写操作需确认                   |
| 执行命令   | 执行 Shell 命令或 Python 代码                |
| 保存记忆   | 沉淀跨会话记忆                               |
| 数据导入   | 结构化数据与 Blob 数据导入                   |

## 知识支撑

AI Query 的分析准确性依赖业务上下文，可从三方面补充：

- **SQL 片段知识库**：导入周期性取数脚本，Agent 检索后可改写日期执行。
- **语义包**：把表、列映射为业务术语、指标与 JOIN 关系，让 Agent 理解业务口径。详见[语义包](./semantic-pack.mdx)。
- **跨会话记忆**：Agent 沉淀业务约定、偏好与结论，在后续会话中自动复用。

## 定时任务

对需要周期执行的分析，在 Quest 全屏模式下创建**定时任务**。调度类型预设每天、工作日、每小时、每周、每月 1 日与延迟执行，页面提供**我的定时任务**与**执行记录**两个标签。

> **提示**：定时任务仅在客户端运行时执行。
