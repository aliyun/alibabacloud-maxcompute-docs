客户端支持两类导入：把本地结构化文件（CSV、Excel、Parquet）的数据写入 MaxCompute 表，或把本地二进制文件写入表的 BLOB 字段。两类导入在导入编辑 Tab 顶部通过开关切换；切换时若已加载文件，会弹出「切换导入类型将清空当前配置，是否继续？」确认框。

## 适用场景

- 把本地 CSV、Excel 或 Parquet 文件导入到 MaxCompute 新建表或已有表。
- 把本地二进制文件批量导入到表的 BLOB 字段。
- 跟踪导入任务的进度与状态，查看日志或下载原始文件。
- 不手动配置，用自然语言发起导入。

## 入口

在左侧活动栏**工作室**组单击**数据导入**图标（上传形状）打开面板，再单击 **+** 按钮在中间区打开导入编辑 Tab。

## 结构化数据导入

1. **选择文件**：单击选择或拖拽文件，支持 CSV、Excel（.xlsx / .xls）、Parquet。
2. **预览数据**：文件解析后展示前 20 行，确认数据无误。
3. **选择导入模式**：**新建表**或**现有表**，见下文两种模式。
4. **配置目标**：选择 Project 连接；目标项目随连接自动填充；填写目标表名，系统实时校验命名合法性与是否已存在。
5. 单击**开始导入**，创建导入任务。

### 新建表

系统根据文件内容推导建表 DDL。可单击 **AI 生成 DDL**，由 AI 优化列类型与注释；DDL 也可在内置编辑器中直接修改后再导入。

### 现有表

选择目标表，数据以追加方式写入。

## Blob 导入

把本地二进制文件导入到 MaxCompute 表的 BLOB 字段。

1. 选择多个文件，或选择整个文件夹。
2. 选择导入模式：
   - **新建表**：配置表字段，DDL 自动生成为事务表，见下表。
   - **现有表**：将文件映射到已有表的 `content` 列。
3. 提交后客户端逐文件上传并写入。

**新建表**模式下可配置以下字段，每个字段可开关、重命名，并可指定主键：

| 字段        | 类型   | 必需 |
| ----------- | ------ | ---- |
| `content`   | BLOB   | 是   |
| `file_name` | STRING | 否   |
| `mime_type` | STRING | 否   |
| `file_size` | BIGINT | 否   |

单文件校验：空文件与超过 1 GB 的文件会被标记为无效。

## 导入任务管理

所有任务在数据导入面板以卡片列表展示：文件名、目标 `项目.表`、类型徽标、大小、状态、进度、时间戳与模式徽标。

任务状态包括：排队、上传、解析、预览就绪、导入中、已完成、失败、已取消。

每个任务支持**查看日志**、**下载原始文件**、**删除任务**。

## 用自然语言发起导入

除手动配置外，可在 AI Query 面板用自然语言描述导入需求，例如「把本地 sales.csv 导入成新表」，支持新建表、现有表、Blob 三种模式。
