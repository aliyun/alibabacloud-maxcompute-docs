通过本页完成 MaxCompute AI数据探索（MaxCompute Desktop）的安装、连接配置和第一次数据查询，确认产品端到端可用。

## 完成目标

- 安装并启动客户端。
- 建立第一个 MaxCompute 数据连接。
- 执行一条查询并查看结果。
- （可选）配置 AI 助手，开始用自然语言探索数据。

## 前提条件

- 一台 macOS 12.3 及以上或 Windows 10 及以上的 64 位电脑。
- 一个可访问的 MaxCompute 项目，以及具有项目访问权限的 AccessKey。
- 网络可访问 MaxCompute 服务所在地域。

## 步骤 1：安装客户端

从产品发布渠道获取安装包并完成安装，详细步骤见[安装与更新](./installation.mdx)。

安装完成后双击启动客户端。首次启动无需任何命令行操作。

## 步骤 2：配置第一个数据连接

1. 在左侧活动栏的**工作室**组中，单击**连接**图标（插头形状）。
2. 单击面板顶部的 **+**，打开新建连接对话框。
3. 填写连接信息：

   | 配置项                | 说明                                |
   | --------------------- | ----------------------------------- |
   | 连接名称              | 便于识别的名称，例如 `daily-dev`    |
   | 鉴权方式              | 默认 AccessKey，表单随所选方式变化  |
   | 区域                  | 选择项目所在地域，Endpoint 自动填充 |
   | 项目名称              | MaxCompute 的 Project Name          |
   | AccessKey ID / Secret | 具有项目访问权限的 AccessKey        |

4. 单击**测试连接**，确认配置无误。
5. 单击**保存并连接**。

连接成功后，左侧 **Catalog** 面板会自动加载该项目的表结构。

## 步骤 3：执行第一条查询

1. 按 **Cmd+N**（Windows 为 Ctrl+N），输入文件名并创建 SQL 文件。
2. 在编辑器中输入查询语句：

   ```sql
   SELECT * FROM <your_table> LIMIT 10;
   ```

3. 按 **Cmd+Enter**（Windows 为 Ctrl+Enter）执行。

查询结果出现在编辑器下方的结果面板，可切换表格、图表、透视等视图，也可导出为 CSV、JSON、Parquet 或 XLSX。

## 步骤 4：（可选）启用 AI 助手

1. 单击标题栏右侧的**齿轮**图标，打开设置。
2. 在**AI 配置**标签页填写：

   | 配置项   | 说明                                     |
   | -------- | ---------------------------------------- |
   | API URL  | AI 服务地址，默认阿里云百炼              |
   | API Key  | 在百炼控制台创建的 API Key               |
   | 模型名称 | 默认提供推荐模型，支持任意兼容接口的模型 |

3. 单击**保存**。

配置完成后，单击标题栏右侧的 AI 按钮展开 **AI Query** 面板，即可用自然语言提问，例如「查看当前项目有哪些表」。

## 验证结果

- Catalog 面板能够浏览表结构，说明连接可用。
- 结果面板返回数据行，说明查询链路可用。
- AI Query 面板能够回答问题，说明 AI 服务可用。
