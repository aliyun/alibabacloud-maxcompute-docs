客户端把 SQL 编写、执行与结果分析集成在同一个工作台中。SQL 脚本、执行历史和版本快照保存在本地，网络中断也不会丢失工作现场。

## 适用场景

- 编写和调试 MaxCompute SQL，需要语法高亮、表列名补全与一键格式化。
- 只执行脚本的一部分：全文、选中片段或单条语句，快速迭代调试。
- 对查询结果做图表可视化、透视汇总与数据质量分析。
- 通过 Logview 的 DAG 阶段概要定位作业性能瓶颈。
- 把结果导出为 CSV / JSON / Parquet / XLSX，或将结果图表固定到数据看板。

## SQL 编辑器

按 **Cmd+N**（Windows 为 Ctrl+N），在弹出的**新建 SQL 文件**对话框中命名并创建新文件（自动追加 `.sql`）；也可在**资源管理器**面板的 **SQL 脚本**文件树中单击已有文件打开。

编辑器对 MaxCompute SQL 做语法高亮。输入时自动弹出补全列表，覆盖 SQL 关键词、内置函数、当前连接下的表名和列名；输入表名后紧跟 `.` 会弹出该表的列名。补全具备上下文感知能力，例如 `FROM` 后优先提示表名；按补全快捷键可手动触发。

按 **Shift+Option+F**（Windows 为 Shift+Alt+F）自动格式化当前 SQL。

## 执行 SQL

| 执行方式 | 操作                                                                                |
| -------- | ----------------------------------------------------------------------------------- |
| 全文执行 | 按 **Cmd+Enter**（Windows 为 Ctrl+Enter）或单击标题栏**运行**按钮，依次执行所有语句 |
| 选中执行 | 选中一段 SQL 后按 **Shift+Enter**，仅执行选中部分                                   |
| 单句执行 | 单击语句左侧的**运行**按钮（▶），仅执行该条语句                                     |

若文件中包含 `SET` 语句，客户端会自动将 SET 配置合并到后续 SQL 一起提交。例如：

```sql
SET odps.sql.type.system.odps2=true;
```

## 脚本与版本管理

- **脚本文件树**：位于**资源管理器**面板上半部分，支持新建、打开、保存、多 Tab 切换、搜索与刷新。
- **版本历史**：在左侧活动栏**工作室**组单击**版本历史**图标，面板自动加载当前打开文件的版本列表。版本分**手动保存**（蓝色）与**执行前快照**（橙色），双击查看 Diff，悬停可恢复或删除某个版本。

## 查询结果分析

SQL 执行完成后，结果面板出现在编辑器下方。顶部工具栏提供 **表格**、**可视化**、**透视**、**质量**、**JSON**、**执行日志**、**Logview** 视图切换，并提供**AI 分析**按钮，一键把当前结果集（SQL、列、行、行数）交给 AI Query 面板做进一步解读；有数据时还可分享到飞书。

### 表格视图

默认视图。支持列头排序与分页浏览，右侧显示返回行数与执行耗时，可对结果行发起行内操作。

### 可视化图表

单击**可视化**按钮进入图表面板：顶部选择图表类型，下方轴配置区选择 X 轴、Y 轴与分组维度，系统按列类型自动推荐映射，图表实时渲染。图表数据点可单击，在看板联动场景中触发交叉过滤。

支持 20 种图表类型，按类别分组：

| 类别       | 图表                                                 |
| ---------- | ---------------------------------------------------- |
| 基础       | 柱状图、条形图（横向）、折线图、面积图、组合图、饼图 |
| 分布与统计 | 散点图、气泡图、直方图、箱型图、瀑布图               |
| 关系与结构 | 桑基图、树图、漏斗图、热力图、雷达图                 |
| 指标       | KPI 指标卡                                           |
| 3D         | 3D 柱状图、3D 散点图、3D 曲面图                      |

### 数据透视表

单击**透视**按钮，配置行维度（1~3 个）、列维度（可选 1 个）、值列（1 个数值字段）与聚合函数（SUM / COUNT / AVG / MIN / MAX），自动计算并展示行列合计。

### 数据质量分析

单击**质量**按钮，系统自动对当前结果做质量扫描，输出：

- 整体评分：按完整性 40%、唯一性 30%、一致性 30% 加权。
- 数据集统计。
- 每列分析卡片：唯一值、空值占比、数值列 min / max / avg / sum、Top 3 高频值。

### Logview 解析

单击 **Logview** 按钮，展示当前作业的 DAG 阶段、各阶段耗时与记录数概要，无需跳转外部页面即可定位性能瓶颈。

## 数据导出

在结果面板工具栏单击下载图标的下拉箭头，选择导出格式：

| 格式    | 说明                           |
| ------- | ------------------------------ |
| CSV     | 逗号分隔文本，内置公式注入防护 |
| JSON    | 结构化 JSON                    |
| Parquet | 列式存储，列数上限 20 列       |
| XLSX    | Excel 工作簿                   |

## Pin 到看板

在结果面板的图表上单击 **Pin**，选择**新建看板**或**添加到已有看板**，当前图表连同 SQL、连接与图表配置一起固定为看板磁贴，持久复用。

## 查询历史

在左侧活动栏**工作室**组单击**查询历史**图标（时钟）。每条记录展示执行时间、耗时、SQL 预览、状态与返回行数；单击记录可在中间区打开只读结果 Tab。支持按连接筛选、搜索、加载更多与删除单条。
