本页按使用场景整理常见故障的处理方法。连接类问题的完整排查步骤见[MaxCompute 连接](./connection.mdx)。

## 安装与启动

### macOS 提示「应用已损坏」或「无法验证开发者」

正式发布包已签名公证，一般不会出现。使用内测包遇到该提示时，在终端执行以下命令后重启应用：

```bash
sudo xattr -rd com.apple.quarantine "/Applications/MaxQuery Studio.app"
```

### AI 面板无响应

确认**设置 ▸ AI 配置**中的 API URL、API Key、模型名称填写正确。默认使用阿里云百炼，需先在百炼控制台创建 API Key。

## 查询与结果

### SQL 报语法错误

MaxCompute SQL 与标准 SQL 存在差异。客户端会自动转写部分语法，但不覆盖全部情况，可对照 MaxCompute SQL 文档调整写法。

### 返回数据量过大

客户端默认对结果做行数限制。需要更多数据时在 SQL 中显式增加 `LIMIT`，或使用结果导出获取完整结果。

### AI 响应慢

受模型负载与网络影响。可在斜杠命令面板把推理档位切换为 **Fast**，或在设置中更换更快的模型。

## 数据导入

### Excel 导入后列类型不正确

导入时自动推断列类型。推断不符预期时，可在新建表模式手动修改 DDL，或使用**AI 生成 DDL** 获得更准确的类型建议。

### Blob 文件导入失败

单文件超过 1 GB 或空文件会被判为无效，检查文件大小与内容后重试。

## 数据看板

### 导出的 PNG 中 3D 图表空白

WebGL 3D 图表（3D 柱状图、散点图、曲面图）离屏渲染存在已知限制，导出 PNG 时可能空白。2D 图表不受影响。

### 保存看板提示「已被其他会话更新」

同一看板在其他位置被编辑，触发了并发保护。按提示重新加载看板后再保存。

## 获取支持

以上方法无法解决时，在**设置 ▸ 关于**中导出诊断日志（前后端运行日志打包为 `.zip`），连同问题描述提供给支持团队。
