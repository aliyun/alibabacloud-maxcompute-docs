## 升级检查

1. 记录现有运行时、组件版本、配置与查询模式。
2. 阅读目标版本说明，固定下载版本或源码 commit。
3. 在隔离环境验证常量查询、目标小表、数据类型和权限。
4. 使用写入能力时，另外核对提交、读回、重试和清理。
5. 把依赖安装、连接成功、真实查询与生产切换分别记录。

下载成功、构建成功或站点 CI 通过，都不是目标项目的运行验收。示例云端验证需由你的授权身份在目标环境执行。
