## 1.11.3 升级要点

- **限定范围内 GA**：MaxFrame Python `table` / `incremental` 模型及 Python 标量、聚合 UDF 正式 GA。MaxFrame 可选依赖、模型返回类型、远端 DAG 取消和 UDF 未支持能力仍有限制，见[模型指南](./guides.mdx#python-模型与-udf)。
- **可选策略**：新增 `truncate_insert`，保留非分区目标表对象并整表替换数据；需显式启用、设置 `full_refresh=false` 并返回完整结果。空结果会清空目标，不改变已有策略默认行为，也不改变权限继承规则。
- **依赖兼容修复**：MaxFrame extra 使用 `pyarrow<26`，匹配 MaxFrame 2.x 的 NumPy 1 约束。安装 `dbt-maxcompute[maxframe]==1.11.3` 后检查依赖一致性，不在现有环境中盲目升级 NumPy/PyArrow。
- **旧版 UDF 升级**：全局 CP311 默认配置延续 1.11.3 beta 行为，但不同于 1.11.2。调用已有 CP27/CP37 函数时须显式配置匹配运行时，hook 和 `dbt show --select` 另有配置要求，见[配置参考](./reference.mdx#python-运行时兼容)。

## 升级检查

1. 记录现有运行时、组件版本、配置与查询模式。
2. 阅读目标版本说明，固定下载版本或源码 commit。
3. 在隔离环境验证常量查询、目标小表、数据类型和权限。
4. 使用写入能力时，另外核对提交、读回、重试和清理。
5. 把依赖安装、连接成功、真实查询与生产切换分别记录。

下载成功、构建成功或站点 CI 通过，都不是目标项目的运行验收。示例云端验证需由你的授权身份在目标环境执行。
