## 记录格式

每个版本按发布日期倒序记录以下内容：

- 版本号和发布日期
- 工具新增、变更和下线
- 协议与客户端兼容性
- 配置、权限和部署变化
- 用户需要执行的操作
- 已知问题和回滚入口
