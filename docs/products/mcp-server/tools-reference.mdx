本页是 MaxCompute MCP Server 工具参考入口，可按工具名称查找用途、输入、输出和权限要求。

## 工具目录

工具按用户目标分组，便于从任务快速定位所需能力。

## 工具条目结构

每个工具条目提供以下信息：

1. 用途、适用场景和副作用。
2. 所需权限和信任边界。
3. 输入参数、类型和约束。
4. 返回结构和错误语义。
5. 经验证的请求与响应示例。
6. 引入版本、兼容性和变更记录。
