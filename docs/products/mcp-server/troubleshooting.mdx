本页提供 MaxCompute MCP Server 常见问题的诊断与恢复方法。

## 开始前收集信息

开始排查前，请记录服务端版本、客户端名称与版本、部署方式、完整错误信息、请求追踪信息和问题发生时间。

## 按阶段定位

请先判断问题发生在进程启动、协议连接、工具发现、实际调用、权限校验还是结果处理阶段，再进入对应条目。

## 仍未解决

如果问题仍未解决，请通过产品支持渠道提交版本、环境和经过脱敏的日志、配置及调用样本。
