通过本页完成 MaxCompute MCP Server 的部署、连接与首次调用。

## 完成目标

完成服务启动、工具发现和一次只读调用，确认服务可以正常使用。

## 前提条件

开始前，请确认运行环境、访问权限、网络条件和所需的 MaxCompute 资源均已准备就绪。

## 操作步骤

按照部署服务、配置客户端、发现工具、执行一次只读调用和核对结果的顺序开始使用。

## 验证结果

完成操作后，请分别确认服务状态、工具发现结果和实际调用结果。

## 下一步

生产环境部署前阅读[安全与权限](./security.mdx)，并在[工具参考](./tools-reference.mdx)确认工具契约。
