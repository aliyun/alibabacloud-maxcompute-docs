本页介绍 MaxCompute MCP Server 的安全边界和权限要求，帮助你在开放工具前完成检查。

## 信任边界

客户端、服务端、MaxCompute 资源和外部依赖之间的数据流向按信任边界说明，并标明各边界的身份校验方式。

## 身份与凭证

身份认证信息包括凭证来源、轮换要求和失效处理。示例不会显示真实凭证。

## 最小权限

权限按工具或任务列出，并区分读操作和写操作。

## 数据与日志

请求、响应、错误和审计记录中的数据均需遵循脱敏和访问控制要求。

## 上线检查

生产开放前，请确认身份、授权、网络边界、工具清单、日志脱敏和撤销路径。
