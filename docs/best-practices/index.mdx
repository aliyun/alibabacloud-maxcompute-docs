每条实践都说明前提、步骤、完成条件与失败后的去向。第一次使用时，先走[准备项目 → 第一条查询](../getting-started/index.mdx)，无需直接安装驱动或搭建计算集群。

## 选择一项任务

| 任务                                                                                    | 适合谁                                     | 完成判据                           |
| --------------------------------------------------------------------------------------- | ------------------------------------------ | ---------------------------------- |
| [用 CLI 与 JDBC 核对同一项目的连接](./verify-connections.mdx)                           | 要把已有 Java 应用接入 MaxCompute 的开发者 | 两个入口返回相同的常量结果         |
| [从可查询项目到可测试的 dbt 模型](./dbt-model-checklist.mdx)                            | 已经选定 dbt 的数据开发者                  | 模型与测试成功，目标表实际读回正确 |
| [用内联数据完成第一次分析](../getting-started/first-query.mdx#5-用内联样例完成一次分析) | 尚无业务样例表的新人                       | 得到确定的两行分组结果，无需创建表 |

## 执行前先核对

确认项目与身份、目标工具版本，以及本次是否会写入数据。只运行一条路径需要的工具；常量查询通过后，再验证业务表、分区和真实数据权限。本站的静态构建检查不代替目标环境执行。
