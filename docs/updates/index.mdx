## 升级前后分别核对

1. 记录当前工具版本、实际依赖与所用功能。
2. 阅读目标版本的兼容性和已知限制，固定安装版本。
3. 在测试环境先运行最小查询，再核对真实对象的读写与结果。
4. 保留失败信息与恢复方案，再决定是否切换生产工程。

页面标记“文档草稿”不等于产品 Beta。下载成功、站点构建成功和目标环境执行成功是不同的检查结果。
