平台使用一个 Docusaurus docs 实例，并按内容域和组件目录提供多套 sidebar。该结构支持团队独立贡献内容，同时避免首期为每个组件复制插件、版本目录和构建配置。

## 内容边界

- `docs/getting-started/`：跨组件入门
- `docs/components/<component-id>/`：组件专属内容
- `docs/best-practices/`：跨组件实践
- `docs/reference/`：公共术语和参考
- `docs/contributing/`：适合站点公开展示的贡献说明

`config/components.json` 是组件入口和首页卡片的单一数据源。组件目录、注册信息和所有权必须保持一致，并由校验脚本阻断漂移。

## 扩展边界

组件仅在确实需要独立维护多个公开版本时迁移为独立 docs plugin。规模过大、构建时间或发布权限需要完全隔离时，再评估拆分为独立站点。
