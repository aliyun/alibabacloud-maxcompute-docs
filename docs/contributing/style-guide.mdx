## 页面结构

每篇页面聚焦一种文档类型和一个用户目标。front matter 提供 H1，正文从 H2 开始，标题层级不超过四级且不跳级。

## 术语和文案

- 产品名使用 `MaxCompute`、`MaxFrame` 等规范拼写。
- 专有名词和缩略语首次出现时给出简短说明。
- 操作步骤使用“登录、选择、单击、填写、确认”等明确动词。
- 不使用绝对化承诺、营销口号和无法验证的性能数据。

## 命令和代码

- 代码块标注 `shell`、`sql`、`python`、`java`、`json` 或 `yaml` 等语言。
- SQL 关键字使用大写并写全分号。
- 示例中的账号、Endpoint、项目和密钥使用规范占位符。
- 多步骤示例说明输入、预期结果和清理方式。

## 图片和外部内容

截图不得包含个人信息、客户数据、内部地址或浏览器书签栏。引用第三方内容时，应确认许可并注明来源。iframe、脚本和分析 SDK 需要按平台代码变更评审。
