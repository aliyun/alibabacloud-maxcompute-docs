MaxCompute 文档平台接受文档内容、新组件接入和平台代码三类贡献。所有变更通过 GitLab 合并请求评审，并由 CI 检查内容契约和生产构建。

## 选择流程

- 修改现有页面时，阅读[编写文档](./write-docs.mdx)。
- 接入新组件时，阅读[接入组件](./add-component.mdx)。
- 本地验证页面时，阅读[本地预览](./local-preview.mdx)。
- 检查格式和术语时，阅读[文档规范](./style-guide.mdx)。

根目录 [CONTRIBUTING.md](https://gitlab.alibaba-inc.com/odps/maxcompute-docs/-/blob/master/CONTRIBUTING.md) 包含完整仓库规则和合并请求验收要求。
