## 准备环境

使用 Node.js 20.17.0 或更高版本。团队基线和 CI 使用 Node.js 24.12.0，包管理器固定为 npm 11。

## 启动开发服务器

```shell
npm ci
npm start
```

访问 `http://localhost:3000`，修改文档后页面会自动刷新。

## 验证生产结果

```shell
npm run ci
npm run serve
```

`npm run ci` 会依次执行格式、Markdown、拼写、文档契约、组件契约、类型和生产构建检查。合并请求流水线还会保存 `build/` 制品，供评审者下载预览。
