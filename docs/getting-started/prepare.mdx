本页的完成条件是：你知道要连接哪个项目，使用什么身份，从当前网络连接哪个 Endpoint。已有这些信息时，直接进入[第一条查询](./first-query.mdx)。

## 1. 使用已有项目，或准备创建项目

- **公司已有项目**：向项目管理员申请加入测试或开发项目，并说明你只需要先执行一条常量 SELECT。不要为了入门自行新建生产项目或申请全量管理权限。
- **尚未开通服务**：按[官方开通指南](https://help.aliyun.com/zh/maxcompute/user-guide/activate-maxcompute-and-dataworks)准备账号并开通服务。开通、购买及资源包资格以控制台和官方说明为准。
- **需要新建项目**：由具有相应权限的人员按[创建 MaxCompute 项目](https://help.aliyun.com/zh/maxcompute/user-guide/create-a-maxcompute-project)操作。创建权限与执行查询的权限不同。

## 2. 准备一份连接清单

| 信息             | 从哪里确认                                                      | 入门检查                                   |
| ---------------- | --------------------------------------------------------------- | ------------------------------------------ |
| 项目名 Project   | 项目管理员或控制台                                              | 使用项目名称，不是产品显示名称             |
| 地域             | 项目管理员或控制台                                              | 与实际项目所在地域一致                     |
| Endpoint         | [官方连接地址](https://help.aliyun.com/zh/maxcompute/endpoints) | 与地域、当前网络匹配；不要照抄其他人的地址 |
| 身份与授权       | 组织已有的 OAuth、RAM、STS 或凭据机制                           | 身份已加入目标项目，并允许执行 SQL         |
| Schema（如使用） | 项目管理员                                                      | 目标命名空间已存在且可访问                 |
| 费用与资源范围   | 项目管理员或账号负责人                                          | 确认允许使用的项目、计算资源和预算         |

不要把真实凭据贴入文档、聊天或 Issue。不同工具的认证方式不同，按所选快速开始配置；无需为了本教程把凭据改成另一种类型。

## 3. 区分身份认证与项目授权

能登录阿里云不等于能查询 MaxCompute。非项目所有者通常还需要加入项目并获得相应权限，见[项目添加用户并授权](https://help.aliyun.com/zh/maxcompute/user-guide/user-planning-and-management)。常量查询不需要已有业务表；读取真实表时还需目标表的读权限。

如果你不是管理员，可以发送下面的申请说明，按实际情况填写，勿附凭据：

```text
我希望在测试/开发项目完成 MaxCompute 入门只读查询。
请确认项目名、地域、可用 Endpoint、身份接入方式，以及执行 SQL 的权限和费用范围。
第一步只运行常量 SELECT，不创建或修改表。
如后续读取样例表，请另行指定获准访问的表、Schema、分区和查询范围。
```

## 4. 确认费用与网络

查询、存储和数据传输可能涉及不同计费项，见[计费项与计费方式](https://help.aliyun.com/zh/maxcompute/product-overview/overview-1)。常量查询减少了准备业务数据的步骤，不表示承诺免费，也不表示所有权限均已通过。

如果 Endpoint 与身份正确但仍连接超时，先检查当前网络能否到达所选地址。公网与专有网络地址不可随意互换；不要通过关闭 TLS 校验绕过连接问题。

## 准备完成

确认清单中的信息可用后，进入[第一条查询](./first-query.mdx)。缺少信息时停在对应步骤，保留已完成的安装检查，不猜测项目名、凭据或权限。
