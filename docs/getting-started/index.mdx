文档中心按产品和使用场景组织内容。先选择产品，再根据任务进入快速开始、使用指南、参考或故障排查。

## 选择入口

| 目标           | 入口                                    |
| -------------- | --------------------------------------- |
| 了解某个产品   | [产品文档](../products/index.mdx)       |
| 查找跨产品方案 | [最佳实践](../best-practices/index.mdx) |
| 了解版本变化   | [更新日志](../updates/index.mdx)        |
| 查询公共术语   | [参考](../reference/index.mdx)          |
| 解决常见问题   | [常见问题](../faq/index.mdx)            |

## 推荐阅读顺序

1. 从产品的“快速开始”完成首次操作。
2. 在“使用指南”中按目标查找步骤。
3. 通过“参考”确认命令、参数或配置。
4. 遇到异常时进入“故障排查”。
