第一次使用，先完成一条不依赖业务表的查询。你只需选一种工具，无需同时安装 CLI、桌面客户端和各类驱动。

## 从你当前的状态开始

| 你的状态                   | 下一步                                   | 完成后得到什么                  |
| -------------------------- | ---------------------------------------- | ------------------------------- |
| 还没有可用的项目或身份     | [准备账号、项目和权限](./prepare.mdx)    | 项目、地域、Endpoint 与可用身份 |
| 已有项目，希望最快看到结果 | [完成第一条查询](./first-query.mdx)      | 一行确定的 `1, hello` 结果      |
| 已能查询，要连接自己的工具 | [按任务选择工具](./client-selection.mdx) | 一条适合自己的快速开始路径      |
| 安装、连接或运行失败       | [常见问题与恢复](../faq/index.mdx)       | 按失败阶段找到下一项检查        |

## 推荐阅读路径

1. **准备**：确认项目、身份、地域、网络与费用范围。
2. **查询**：执行常量 SELECT，核对结果；不创建或删除业务表。
3. **理解**：了解 [Project、Schema、分区和作业](../reference/index.mdx)。
4. **应用**：选择一种工具，继续自己的集成或[跨工具核验](../best-practices/verify-connections.mdx)。

准备好项目后，优先按[第一条查询](./first-query.mdx)逐步操作。耗时受安装、授权和网络影响，不承诺固定分钟数。

## 这个站点提供什么

本站维护 CLI、桌面客户端、MCP、驱动与连接器的入门和集成指南。SQL 语法、服务开通、资源管理和计费的完整说明仍由[阿里云 MaxCompute 官方文档](https://help.aliyun.com/zh/maxcompute/)提供；SDK 继续使用[既有官方文档](https://aliyun.github.io/aliyun-odps-java-sdk/)。不必为阅读 SQL 参考先安装全部工具。

标有“文档草稿”的页面表示内容仍在完善，不代表对应产品能力处于预发布。产品 GA 范围以各产品的版本说明为准。
