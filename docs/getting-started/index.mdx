文档中心按“跨组件内容”和“组件内容”两类组织。组件内容位于稳定的英文目录中，展示名称和页面标题可以独立调整，不会因此改变公开 URL。

## 选择入口

| 目标           | 入口                                    |
| -------------- | --------------------------------------- |
| 了解某个组件   | [组件文档](../components/index.mdx)     |
| 查找跨组件方案 | [最佳实践](../best-practices/index.mdx) |
| 查询公共术语   | [参考](../reference/index.mdx)          |
| 提交或维护内容 | [参与贡献](../contributing/index.mdx)   |

## 识别页面状态

- `published`：页面已经具备可使用的内容，并经过对应维护者确认
- `draft`：页面入口已经建立，内容仍需维护者补充或验证
- `deprecated`：页面对应的能力或版本进入下线流程，应同时提供迁移说明

页面状态位于每篇文档的 front matter 中。草稿页面不应被当作已确认的产品说明。
