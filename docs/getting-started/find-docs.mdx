## 按产品查找

打开[产品文档](../products/index.mdx)，选择桌面客户端、CLI、MCP、JDBC、ODBC、Spark、dbt 或 Flink。每个产品拥有独立导航，同时保留快速开始、使用指南、参考、故障排查和版本说明等公共页面类型。

## 按任务查找

- 需要首次跑通时，选择“快速开始”。
- 需要理解术语和机制时，选择“核心概念”。
- 需要完成具体操作时，选择“操作指南”。
- 需要查询参数、接口或兼容性时，选择“参考”。
- 遇到错误或异常时，选择“故障排查”。

也可以使用页面顶部的搜索框，按产品名称或任务关键词查找内容。

## 用关键词搜索

可输入产品名与任务，例如 `JDBC 连接`、`dbt 升级`、`创建项目`。搜索支持分开的关键词，并在标题与摘要中标出匹配内容；可用“搜索范围”缩小到一个产品。

按 `⌘ K`（macOS）或 `Ctrl K` 打开搜索，使用上下方向键选择结果、Enter 打开、Esc 关闭。没有结果时，减少关键词或切回“全部文档”，也可直接[按任务选择工具](./client-selection.mdx)。
