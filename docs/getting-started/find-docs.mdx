## 按产品查找

打开[产品文档](../products/index.mdx)，选择 MaxCompute CLI、MaxCompute MCP Server 或 MaxCompute Desktop。每个产品拥有独立导航，同时保留快速开始、使用指南、参考、故障排查和版本说明等公共页面类型。

## 按任务查找

- 需要首次跑通时，选择“快速开始”。
- 需要理解术语和机制时，选择“核心概念”。
- 需要完成具体操作时，选择“操作指南”。
- 需要查询参数、接口或兼容性时，选择“参考”。
- 遇到错误或异常时，选择“故障排查”。

也可以使用页面顶部的搜索框，按产品名称或任务关键词查找内容。
