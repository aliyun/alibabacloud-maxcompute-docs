## 按组件查找

打开[组件文档](../components/index.mdx)，选择 MaxCompute、MaxFrame、SDK、连接器或开发工具入口。每个组件使用相同的页面类型，便于在不同组件之间切换。

## 按任务查找

- 需要首次跑通时，选择“快速开始”。
- 需要理解术语和机制时，选择“核心概念”。
- 需要完成具体操作时，选择“操作指南”。
- 需要查询参数、接口或兼容性时，选择“参考”。
- 遇到错误或异常时，选择“故障排查”。

搜索服务将在索引和访问参数就绪后启用。在此之前，可以使用侧栏、组件总览和浏览器页面查找功能定位内容。
