## 接入契约

- [ ] 产品已经进入 `handbook/roadmap.md` 的公开范围
- [ ] 已创建 `docs/products/<product-id>/`
- [ ] 已提供概览、快速开始、指南、参考、故障排查和版本说明入口
- [ ] 已更新 `config/products.json`
- [ ] 已更新 `.gitlab/CODEOWNERS`
- [ ] 首页入口、浏览菜单和产品 sidebar 可以访问
- [ ] `npm run check:products` 通过
- [ ] `npm run ci` 通过
- [ ] 已检查桌面端菜单和移动端导航
