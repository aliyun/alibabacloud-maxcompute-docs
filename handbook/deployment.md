# 部署接入

## 当前状态

GitLab CI 已执行生产构建并保存 `build/` 制品。生产托管、Review App 和自动发布尚未启用，仓库不包含虚构的发布目标。

## 接入前确认

- 真实站点地址和 `baseUrl`
- 公网、内网或鉴权后的可见性
- 默认分支和发布权限
- 静态资源缓存和失效策略
- 内容安全策略和其他安全响应头
- 受保护、已屏蔽、最小权限的发布凭据
- 回滚到上一制品的方式
- 搜索爬虫访问范围

## 构建参数

通过受保护的 CI 变量配置：

```text
DOCS_SITE_URL=https://<真实站点域名>
DOCS_BASE_URL=/
```

子路径部署时，`DOCS_BASE_URL` 使用带前后斜线的值。

## 发布任务约束

发布任务只允许默认分支或受保护标签触发，并与合并请求校验分离。使用 `resource_group` 或目标平台的等价能力串行发布，避免并行流水线相互覆盖。部署失败时保留上一个可用制品，不直接修改 Git 历史。
