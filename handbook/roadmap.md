# 产品文档路线图

本路线图只管理哪些产品进入统一文档站点，不代表产品功能、发布时间或支持承诺。产品能力和上线信息必须由对应维护者基于权威来源确认。

## 一期公开范围

| 产品 ID      | 展示名称              | 文档状态 | 说明                         |
| ------------ | --------------------- | -------- | ---------------------------- |
| `cli`        | MaxCompute CLI        | 骨架     | 先建立产品空间和贡献责任边界 |
| `mcp-server` | MaxCompute MCP Server | 骨架     | 先建立产品空间和贡献责任边界 |
| `desktop`    | MaxCompute Desktop    | 骨架     | 先建立产品空间和贡献责任边界 |

一期产品可以出现在首页、产品浏览菜单、全站搜索和公开 sidebar 中。页面内容未获权威来源确认前保持 `draft`，不得补写具体命令、参数、兼容性或产品行为。

## 二期候选

| 候选产品              | 当前状态 | 一期约束                                     |
| --------------------- | -------- | -------------------------------------------- |
| MaxCompute SDK        | 候选     | 不创建公开产品空间，不加入首页、导航或注册表 |
| MaxCompute Connectors | 候选     | 不创建公开产品空间，不加入首页、导航或注册表 |

候选项不构成接入承诺。进入公开范围前必须完成目标读者、内容边界、权威来源、维护者、版本策略和下线责任人评审，并按 [产品接入契约](product-onboarding.md) 提交完整变更。

## 调整规则

- 新增候选项先修改本路线图，不同时创建公开入口。
- 候选项进入公开范围时，在同一变更中更新路线图、产品注册表、目录、导航和 CODEOWNERS。
- 已公开产品退出范围时，先提供替代入口、重定向和归档方案。
- 访问控制、独立部署或版本生命周期无法共享时，通过 ADR 评估是否迁移为独立 docs plugin 或独立站点。
