# ADR 0001：单一站点承载多产品文档空间

- 状态：已接受
- 日期：2026-08-28

## 背景

平台需要托管多个产品，但当前没有访问控制、独立部署或版本生命周期必须完全隔离的证据。为每个产品复制站点会增加导航、搜索、主题、贡献和发布流程的维护成本。

## 决策

使用一个 Docusaurus 站点和一个默认 docs plugin，通过稳定产品目录和多套 sidebar 承载 MaxCompute CLI、MaxCompute MCP Server 与 MaxCompute Desktop。产品注册表驱动首页和浏览菜单入口，校验脚本保证目录和登记一致。

## 结果

三个产品共享站点外壳、搜索、质量门禁和发布流程，同时保留独立内容所有权。某产品出现独立版本生命周期后，可以保持原 URL 迁移为独立 docs plugin；访问控制、发布权限或构建规模无法继续共享时，再评估独立站点。
