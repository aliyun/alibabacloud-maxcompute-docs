# ADR 0002：初始化阶段不启用文档版本化

- 状态：已接受
- 日期：2026-08-28

## 背景

Docusaurus 默认实例的版本命令会复制该实例下的全部文档。当前组件共享默认实例，整体快照会把不同生命周期绑定在一起。

## 决策

默认实例不创建版本快照，也不执行整体版本命令。Docusaurus 3.10.2 不允许在尚未创建版本的站点设置 `disableVersioning: true`，因此不使用该配置。组件只有在需要同时维护多个公开版本、具备维护者和归档规则时，才迁移到独立 docs plugin 并启用版本化。

## 结果

普通内容合并不创建文档快照。未来迁移必须保持 `routeBasePath`，并验证历史链接和导航。
